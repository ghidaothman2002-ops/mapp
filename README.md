# من هنا | خريطة السعودية الزراعية التفاعلية

خريطة سياحية فنية مستقلة باستخدام React وVite، بالعربية وRTL. تبدأ بخريطة المملكة كاملة دون أي بطاقة معلومات؛ تُفتح بطاقة المنطقة عند اختيارها فقط.

## التصميم والتفاعل

- ورق دافئ وألوان رملية وزيتونية وبحرية هادئة، ورسومات فنية للنخيل والواحات والبساتين والمدرجات والجبال والمراكب.
- حدود المناطق الإدارية الـ13 من GeoJSON حقيقي معمّم للعرض. الرسم المرجعي مصدر أسلوب، وليس مصدر حدود. الطبقات الفنية مستقلة عن أشكال التفاعل؛ لا توجد صورة خريطة ثابتة فوقها أزرار.
- أسماء المناطق الـ13 ظاهرة، مع تحديد ناعم عند التركيز أو المرور والضغط.
- بطاقة بجانب الخريطة على الكمبيوتر، وبطاقة سفلية قابلة للتمرير والتصغير والإغلاق على الجوال. يمكن اختيار منطقة أخرى دون تحميل الصفحة.
- مدن وتصفية، محاصيل عند وجود محتوى أولي، عارض تجارب بأسهم ونقاط، تفاصيل، ومعرض صور حقيقية موثقة من المنطقة، مع بديل فني عند نقص الصور.
- دعم لوحة المفاتيح واللمس والتكبير بإصبعين والسحب بعد التكبير وإعادة الضبط. الحركات تحترم تقليل الحركة.
- لا حجز أو أسعار أو مزارع تجارية مخترعة أو روابط للموقع الأساسي.

## التشغيل والتحقق

Node.js 24 وnpm 11 مستخدمان في بيئة التنفيذ:

```sh
cd /workspace/min-huna-map
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

المسار `/mapp/`. في جهاز آخر يمكن تشغيل `npm ci` دون خيار الكاش. لا تحتاج إلى Git worktree إضافي؛ استخدم مجلد المشروع الحالي.

```sh
npm run test:data
npm test
npm run build
npm run preview -- --port 4173
```

اختبارات المتصفح تستخدم `/usr/bin/chromium` في البيئة الحالية. في بيئة أخرى اضبط `CHROMIUM_PATH`، أو شغّل `CI=1` مع `npx playwright install --with-deps chromium` لاستخدام متصفح Playwright. تحقق من نجاح الاختبارات الفعلي؛ لا تعتبر مجرد فتح المنفذ دليل جاهزية.

## ملف تفاعلي للمراجعة دون خادم

```sh
npm run build
python3 scripts/portable-preview.py
```

ينتج `dist/min-huna-map-interactive.html`، وفيه التطبيق والخريطة والرسومات والخطوط كاملة. يمكن تنزيله وفتحه في متصفح حديث دون npm أو اتصال. هذه نسخة تفاعلية، وليست صورة. اختُبرت بتحميل محتواها في Chromium، بما فيه البطاقات والأسهم والصور الفنية، دون أي طلب HTTP. سياسة المتصفح في بيئة التنفيذ تمنع التنقل إلى `file://`، لذلك لم يُدعَ اختبار سياسة فتح الملفات في جهاز المستخدم.

واجهة إعداد البيئة الحالية لا تتيح مشاركة منفذ الخادم عبر رابط ويب عام، ولم يُنشأ نفق خارجي أو يُنشر الموقع. الملفات المحلية ليست روابط استضافة عامة.

## بنية المشروع

- `src/MapCanvas.jsx`: حدود المناطق، طبقات الفن والماء والرمل، التسميات، اللمس والتحريك.
- `src/RegionCard.jsx`: بطاقة المنطقة والتصفية وشرائح التجارب والبطاقة السفلية.
- `src/Artwork.jsx`: مشاهد مستقلة من لوحة الرسومات، تُعرض بقص SVG قابل للتطوير.
- `src/data/regions.js`: المحتوى الأصلي محفوظ، مع المراجع والأسماء.
- `src/data/tourism.js`: تغطية المناطق الـ13، مواقع الرسومات، وحالة الصور والتحقق.
- `src/data/photos.json`: 26 صورة موثقة مع المصور والترخيص والمصدر وبصمة الملف المحلي.
- `public/photos/`: الصور الحقيقية المحلية.
- `PHOTOS.md`: جدول نسب الصور وتراخيصها.
- `src/data/*.geojson`: الحدود والجزر الساحلية.
- `src/style.css`: الهوية والتخطيط المتجاوب.
- `public/art/tourism-atlas.png`: لوحة رسوم مولدة للمشروع، ليست صورًا فعلية.
- `src/assets/brand/`: مكان ملف الشعار الرسمي الأصلي.
- `tests/map.spec.js`: 8 اختبارات متصفح تشمل النقر الحقيقي على المناطق الـ13.
- `scripts/data.test.mjs`: 4 اختبارات لاتساق البيانات والحدود والمحتوى وحقوق الصور.
- `docs/screenshots/vintage-*.png`: صور التحقق البصري.
- `docs/archive/`: نسخة من الواجهة السابقة قبل إعادة التصميم.

## الصور والمحتوى والشعار — ما بقي

**هذه نسخة تصميم تفاعلية للمراجعة، وليست اعتمادًا نهائيًا للمحتوى الزراعي.**

أصبحت نطاقات الصور والمراجع متاحة بعد تحديث البيئة. بُحثت الصور عبر Commons API، وقُرئت أوصاف مواقعها وتراخيصها، ثم حُمّلت 26 صورة محليًا وفُحصت بصريًا. تغطي الصور المناطق الـ13 دون تكرار الصورة بين المناطق؛ صورة الحدود الشمالية معلم حضري في عرعر وليست مزرعة. تستعمل البطاقة صورًا فعلية وفي حالة نقص صور إضافية تستعمل بديلًا فنيًا واضحًا. معلومات المصدر والمصور والترخيص ظاهرة داخل البطاقات وحوار المصادر، ومحفوظة في `photos.json` و`PHOTOS.md`. لا تعني الصور وجود نشاط تجاري أو مضيف متاح.

المحتوى الزراعي الأصلي محفوظ في `regions.js`، لكن تأكيد المحاصيل على مستوى كل مدينة لم يكتمل. النبذات الظاهرة في البطاقات تصف مشاهد الصور الموثقة، دون اختلاق إحصاءات أو قائمة محاصيل للمناطق السبع الجديدة. قُرئ وصف اليونسكو لممارسات زراعة البن الخولاني في السعودية؛ هذا لا يثبت وجود البن في كل مدينة مذكورة. صفحات البحث المطلوبة في موقع الوزارة عادت إلى الصفحة الرئيسية، ولم تُعتبر دليلًا على صحة الادعاءات. جميع أسماء التجارب مقترحات وليست أسماء مزارع أو أنشطة تجارية حقيقية.
الشعار ظهر كمرفق مرئي في المحادثة، لكن لم تتوفر نسخة ملف قابلة للقراءة لأدوات التنفيذ. لم يُعَد رسمه. الاسم النصي في رأس الصفحة مؤقت. لإكمال الربط كما هو، ضع الملف الأصلي باسم `src/assets/brand/min-huna-logo.png` أو svg/jpg/webp؛ يتعرف عليه التطبيق ويضبط مساره عند البناء.

حُفظت نطاقات المصادر والصور وتعليمات التثبيت والتشغيل في مسودة إعدادات البيئة، مع الحفاظ على إعدادات package_managers. نجاح الوصول الحالي تحقق بالطلبات الفعلية؛ حفظ المسودة نفسه لا يثبت نشر نسخة البيئة أو استعادة المشروع في مهمة جديدة. نشر البيئة السحابية مستقل عن نشر الموقع على GitHub Pages. لا يُنشأ نشر Pages دون الموافقة.

## GitHub Pages

`vite.config.js` مضبوط على `/mapp/`. الأصول محلية، والنشر في `.github/workflows/pages.yml` يعمل عند رفع تغييرات إلى `main`، ويمكن تشغيله يدويًا أيضًا (`workflow_dispatch`).

لم يُرفع المشروع إلى GitHub أو يُنشر على Pages. بعد الموافقة، يمكن ربط هذا المستودع المحلي بالمستودع `min-huna-map` وتشغيل النشر اليدوي. نجاح الاختبار المحلي لا يثبت نجاح استضافة Pages.
