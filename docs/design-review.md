## دلالات الرموز

الزيتون للجوف وتبوك؛ النخيل والتمور للقصيم والشرقية؛ النخيل والمزارع للرياض؛ النخيل للمدينة ونجران؛ القمح لحائل؛ الجبال لمكة؛ المدرجات لعسير؛ الرمان للباحة؛ المانجو لجازان؛ نباتات صحراوية للحدود الشمالية. النباتات الصحراوية رمز للبيئة، ولا تدل على زراعة تجارية في الشمال.

هذه اختيارات دلالية وفق موجز المستخدم ومعرفة المحاصيل العامة، ولا تعني أن المحصول حصري للمنطقة أو أنها الأكبر إنتاجًا. لم تُضف أسماء مزارع أو إحصاءات أو أنشطة تجارية أو معلومات جديدة إلى بطاقات المناطق.

محاولة التحقق الإضافي من صفحات وزارة البيئة والمياه والزراعة ونتائج بحث وكالة الأنباء السعودية لم تنتج نصوص مقالات زراعية قابلة للتوثيق: صفحات بحث الوزارة أعادت قالب الرئيسية، ونتائج واس تعتمد على التحميل الديناميكي. لذلك لا تُسجّل هذه الزيارات كتأكيد مستقل لجميع دلالات المحاصيل، وتبقى حالة التوثيق السابقة للمحتوى كما هي. المصادر السابقة محفوظة في `SOURCES.md` والواجهة.

## المراجعة والتشغيل

الأوامر من `/workspace/min-huna-map`:

```sh
npm run dev -- --port 5173 --strictPort
npm run test:data
npm test
npm run build
python3 scripts/portable-preview.py
```

المعاينة المستقلة الناتجة: `dist/min-huna-map-interactive.html`، تُفتح محليًا في متصفح حديث دون فك أرشيف أو تثبيت Node. تحفظ نسخة المراجعة في `exports/design-review.html`. لا يلزم رفعها إلى GitHub Pages.

فحوص المتصفح تشمل الضغط الفعلي على المناطق الـ13، الصور، التصفية والتفاصيل، لوحة المفاتيح، اللمس والتكبير والسحب، وعدم تداخل أسماء المناطق والرموز أو قصّ النصوص على شاشات 1440 و1024 و768 و390 و360 بكسل. صور المراجعة المحفوظة في `docs/screenshots/simple-*.png`.
